# Tic-Tac-Toe

**Tic-Tac-Toe** is a classic two-player game implemented as an interactive application. The game features a simple and intuitive interface, allowing users to play against  an AI opponent.

## Features

- **AI Opponent**: Challenge yourself against a computer-controlled opponent with varying difficulty levels.
- **Responsive Design**: The game board adjusts to different screen sizes, providing a seamless experience on both desktop and mobile devices.
